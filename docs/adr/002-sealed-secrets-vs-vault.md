# ADR-002: Стратегия управления секретами (Sealed Secrets + SOPS)

## Статус
Принято

## Контекст
Нам нужно хранить секреты в Git (GitOps), но не в открытом виде. HashiCorp Vault мощнее, но требует отдельной инфраструктуры и сложного bootstrap.

## Решение
Используем комбинированный подход:
1. **Sealed Secrets:** Для статических секретов (пароли БД, брокеров). Позволяет хранить зашифрованные YAML прямо в репозитории. Ключ хранится в SOPS.
2. **SOPS + Age:** Для шифрования самого мастер-ключа Sealed Secrets и чувствительных конфигов Terraform.
3. **Vault (Планируется):** Для динамических секретов (временные токены AWS/Yandex) в будущем.
