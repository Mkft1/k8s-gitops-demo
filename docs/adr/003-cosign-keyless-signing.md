# ADR-003: Keyless Signing образов через Cosign и GitHub OIDC

## Статус
Принято

## Контекст
Традиционное подписание образов требует хранения приватных ключей в CI (GitHub Secrets), что создает риск компрометации supply chain.

## Решение
Используем **Cosign Keyless Signing**.
- GitHub Actions получает краткосрочный OIDC токен.
- Cosign использует этот токен для подписи в Rekor (Transparency Log).
- **Преимущество:** Ключи не хранятся и не ротируются вручную. Подпись привязана к конкретному коммиту и ветке.
